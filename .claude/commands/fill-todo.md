---
description: 제공한 자료(메모, 회의록, 위키 내용 등)로 지정한 문서의 TODO를 채웁니다
argument-hint: <문서 경로 또는 프로젝트 slug> [자료 파일 경로...]
---

인수인계 문서의 빈 항목을 채웁니다. 인자: `$ARGUMENTS`

## 대상과 자료 확인

- 첫 인자가 `docs/` 아래 `.md` 파일이면 그 파일만 다룹니다.
- 첫 인자가 프로젝트 slug면 `docs/<slug>/` 전체에서 TODO가 남은 페이지를 대상으로 합니다.
- 나머지 인자는 자료 파일 경로입니다.
  - 파일이 없으면 이 대화에서 사용자가 붙여넣은 내용을 자료로 씁니다.
  - 그것도 없으면 어떤 자료를 줄지 물어보고 멈춥니다.

## 작성 규칙 (CLAUDE.md 준수)

1. **자료에 근거가 있는 내용만** 채웁니다. 추측으로 버전, URL, 담당자, 절차를 만들지 않습니다.
2. 자료에 비밀 값(비밀번호, 토큰, 키)이 있으면 문서에 옮기지 않습니다. "보관 위치"만 적고, 사용자에게 해당 값이 자료에 있었다고 알립니다.
3. 자료로 채울 수 없는 칸은 비워 두고 `<!-- 확인 필요: 무엇을 누구에게 -->` 주석을 남깁니다.
4. 페이지의 필수 항목이 모두 채워졌을 때만 상단 `::: warning TODO` 블록을 지웁니다.
5. 기존 표 형식, 제목 구조, 링크 규칙을 유지합니다.

## 마무리

1. `npm run docs:build`로 빌드를 확인합니다.
2. 다음을 보고합니다.
   - 채운 항목: 페이지별로 요약
   - 자료가 부족해 남긴 항목: 사용자가 누구에게 무엇을 확인해야 하는지 목록으로
3. 커밋은 하지 않습니다.
