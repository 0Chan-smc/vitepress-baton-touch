인수인계 문서를 점검해 보고서를 만듭니다. 대상은 `$ARGUMENTS`입니다. 비어 있으면 `.vitepress/projects.mjs`의 모든 프로젝트를 점검합니다.

**파일은 수정하지 않고 보고만 합니다.**

## 점검 항목

1. **남은 TODO**: 페이지별로 셉니다.
   - `::: warning TODO` 블록
   - `<!-- ... -->` 빈칸 주석
   - 빈 표 행(`| | |`)
2. **비밀 값 의심**: 실제 값처럼 보이는 문자열을 찾습니다.
   - `password`, `비밀번호`, `token`, `secret`, `api key`, `AKIA`, `sk-`, `-----BEGIN` 패턴
   - 휴대전화 번호 형식
   - 발견 시 파일:줄과 함께 보여 주되, **값 자체는 보고서에 옮기지 않고 가립니다.**
3. **링크**: `npm run docs:build`를 실행해 dead link 오류를 확인합니다.
   - 다른 프로젝트 경로를 가리키는 링크(예: project-b 문서 안의 `/project-a/`)도 찾습니다.
4. **사이드바 누락**: `docs/<slug>/` 아래 `.md` 파일 중 `.vitepress/config.mts`의 `projectSidebar()`에 없는 페이지를 찾습니다.
5. **인수 완료 체크리스트**: 각 프로젝트 `index.md`의 체크리스트 진행률을 확인합니다.

## 보고 형식

- 프로젝트별 표를 만듭니다. 열은 페이지, 남은 TODO 수, 문제를 둡니다.
- 맨 위에 "바로 조치할 것"을 우선순위 순으로 3~5줄 적습니다. 비밀 값 의심이 가장 먼저입니다.
